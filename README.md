## 🚀 Comment démarrer

1. Clonez le dépôt :  
```bash
git clone https://github.com/tonuser/colorimetrie-ia.git
cd colorimetrie-ia
```

2. Installez les dépendances :  
```bash
pip install -r requirements.txt
```
3. Lancez le dashboard :

```bash
streamlit run app.py
```
